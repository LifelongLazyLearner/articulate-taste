# Taste Bud

Taste Bud is an evidence-based personal taste profile for making and evaluating creative work, products, code, and leadership decisions.

Taste is treated here as stable values and standards of judgment, not as a fixed visual style, tone, or structure. Its expression should change with the work, medium, audience, and intended effect.

[`TASTE.md`](TASTE.md) is the single canonical profile. It contains the active principles, their evidence and boundaries, a practical decision test, and the threshold for future revisions.

The profile is guidance, not automatic authority. Using it in another project requires an explicit reference or instruction in that project's applicable context. It does not override user constraints, factual evidence, safety requirements, or project-specific pass conditions.
